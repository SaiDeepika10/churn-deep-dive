## 📌 Problem Statement

A SaaS company is losing customers but doesn't know why. Leadership sees churn going up month-over-month but has no systematic way to:
- Identify **who** is about to churn before they cancel
- Understand **why** they leave (root causes)
- **Act** on that insight automatically at scale

This project solves all three.

## 📊 Key Findings

| Metric | Value |
|--------|-------|
| Avg monthly churn rate | **6.2%** (↑ 1.8pp YoY) |
| Highest-risk cohort | Customers aged **0–30 days** (15.6% churn) |
| Highest-risk channel | **Paid social** (18.2% churn vs 2.9% referral) |
| #1 churn reason | **Price** (34%) — followed by missing features (27%) |
| Best churn predictor | **7-day inactivity** (precision 71%, recall 68%) |
| Feature with biggest churn gap | **Integrations** — non-users churn at 5× rate |

---

## 🔮 Leading Indicators (Pre-Churn Signals)

Signals that appear **14–30 days before cancellation**:

| Signal | Churn Rate | Precision | Recall |
|--------|-----------|-----------|--------|
| Inactivity ≥ 7 days | 31% | 71% | 68% |
| Usage drop ≥ 50% WoW | 28% | 66% | 72% |
| 3+ unresolved tickets | 21% | 58% | 55% |
| Integration removed | 24% | 62% | 41% |
| NPS ≤ 4 | 17% | 52% | 48% |
| No email opens 4+ weeks | 12% | 40% | 61% |

**Signal stacking**: Customers with 4+ signals have a **78% churn probability**.

## 🎮 Churn Playbook

### Automated Triggers

| Rule | Trigger | Expected Impact |
|------|---------|----------------|
| Re-engagement email | `last_login >= 7 days` | Prevents ~22% of churns |
| In-app feature nudge | `wk_sessions / prev < 0.5` | Prevents ~18% of churns |
| NPS follow-up survey | `nps_score <= 4` | 38% response rate |
| Downgrade/upgrade offer | `last_login >= 14 days AND plan = 'starter'` | 31% cancellation avoided |

### Human-Led Interventions

| Rule | Trigger | Expected Impact |
|------|---------|----------------|
| Assign dedicated CSM | `mrr >= $500 AND risk_signals >= 2` | Prevents ~44% of churns |
| Escalation call | `open_tickets >= 3 AND age >= 5 days` | 74% resolution rate |
| 30-day onboarding check-in | `tenure_days IN (7,14,30)` | -29% month-1 churn |

## 💡 What Makes This Different

Most churn projects stop at prediction. This one goes further:

1. **Root cause analysis** — not just "who churns" but "why"
2. **Churn playbook** — rules mapped to real business actions
3. **Signal stacking** — quantifies how risk compounds across indicators
4. **Segmentation depth** — acquisition channel × tenure × feature adoption
